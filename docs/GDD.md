# 《试剂纪元》设计文档（GDD）

版本 0.1 · 2026-11-14

---

## 1. 定位

**一句话**：你被困在元素裂谷，手上只有随机发放的试剂。让两种物质反应，才能伤到怪物。

| 维度 | 取值 |
|---|---|
| 类型 | 回合制卡牌对战 / 教育向 |
| 平台 | 网页（横屏 16:9），可打单文件离线包 |
| 单局时长 | 4–9 回合，约 60–90 秒 |
| 总时长 | 12 关，约 15 分钟 |
| 教学范围 | 人教版九年级 → 必修第一册/第二册 → 选择性必修1 |
| 明确不做 | 元素周期律、有机化学 |

**核心取舍**：玩家不手写化学式，而是**从手牌里挑物质 + 判断能否反应 + 配平**。
理由：书写化学式会把节奏拖成做题；而「判断两种物质能不能反应」才是初中化学最核心的能力。
配平作为**可选的额外奖励**，而不是强制关卡。

---

## 2. 核心循环

```
一局战斗
 ├─ 每回合：抽 2 张 → 选任意张 → 出招
 │    ├─ 不能反应 → 浪费一回合，敌方白打一次（惩罚判断失误）
 │    └─ 能反应 → 立即结算基础伤害
 │         └─ 配平面板（8–15 秒，可跳过）
 │              ├─ 跳过/超时   ×1.0
 │              ├─ 配平正确    ×1.15 +1 能量
 │              └─ 完美配平    ×1.30 +2 能量（剩余时间 > 一半）
 │         └─ 「正确方程式」卡片：显示标准写法与现象、陷阱，
 │            由玩家自己关闭后才继续（记忆用，不自动消失）
 └─ 敌方回合：攻击或技能 → 抽牌 → 下一回合
```

**辅助机制**

- **提示**：每关 3 次，高亮一组能反应的手牌（优先命中弱点的组合），只告诉「这几张能反应」，
  不揭示产物。解决的是「8 张牌 28 种组合，玩家找不到」而不是「发牌太差」。
- **不反应提示**：选错组合时暂停流程，弹窗说明并让玩家确认，然后才走敌方回合。
- **死手保底**：手牌一张都打不出时，把整副牌重排并**保证**新手里有一组可反应的组合。
  实测真正的死手率在多数关卡是 0%，第 2、5 关起手约 10%。

> 选择数量不设上限：有些方程式本身就是三四个反应物
> （`4Fe + 3O₂ + 6H₂O`、`Al₂O₃ + 2NaOH + 3H₂O`），限制成 2 张会把它们全部堵死。

**能量**用于「强化」：消耗 1 点让这一击 ×1.25。
于是闭环成立：**配平换能量 → 能量换伤害**。配平从考试变成了资源操作。

**回合上限**：`16 + 敌人血量/120`。超出即失败——这是防止玩家靠穷举试出反应的唯一手段。

## 3. 伤害模型

```
伤害 = 18 × 类型系数 × 条件系数 × 配平精度 × 弱点倍率 × (1 + 连击) × 强化 × 护甲
```

### 3.1 类型系数与附加效果

| 类型 | 系数 | 附加效果 |
|---|---|---|
| 中和 | 1.0 | 净化：清除自身异常 |
| 沉淀 | 1.1 | 成壳：自身 +12 护盾 |
| 复分解 | 1.1 | 成壳：自身 +12 护盾 |
| 置换 | 1.2 | 腐蚀：敌方护甲 −1 |
| 分解 | 1.2 | 催化：额外抽 1 张 |
| 产气 | 1.3 | 窒息：敌方下回合伤害 −30% |
| 化合 | 1.5 | — |
| 氧化还原 | 1.6 | 灼烧：敌方 3 回合持续掉血 |
| 燃烧 | 2.0 | 灼烧 |

### 3.2 条件系数

常温 1.0 / 催化 1.15 / 加热 1.25 / 点燃 1.3 / 通电 1.3 / 高温 1.4

### 3.3 弱点与抗性

每个敌人有 `weakness` 与 `resist` 两个反应类型列表，命中弱点 **×2**，被抗性削弱 **×0.5**。
这是「化学知识 → 战术」的唯一转化点：打对类型比配平快更重要。

### 3.4 其他

- 连击：连续命中弱点，每次 +10%，上限 +50%
- 护甲：`max(0.4, 1 − 护甲 × 0.12)`
- 灼烧：每回合固定 6 点

### 3.5 已经过模拟验证

`scripts/sim.ts` 用随机策略把 12 关各跑 60 局，检查卡死与胜负分布。
**任何数值调整后必须重跑**，目标：普通关 4–7 回合、Boss 7–10 回合、模拟胜率 85–95%。

## 3.6 反应判定：规则引擎（不是查表）

早期版本只认手写反应表，表里没有的配对一律判「不反应」——
Zn + CuSO₄ 这种教科书反应都会被拒。现在是三层结构：

```
lookupReaction(a, b)
  ├─ 1. 手写反应表命中 → 直接用（有现象、教材出处、陷阱提示）
  ├─ 2. 规则引擎推断 → 产物 + 类型 + 条件
  └─ 3. 通用配平器求系数 → 定稿；求不出则判「不反应」
```

规则引擎（`src/engine/chem.ts`）的做法：

1. 用「枚举所有阴阳离子组合」反查化学式，得到每种物质的离子构成
2. 按物质类别套规则：

| 规则 | 判断依据 | 生成物 |
|---|---|---|
| 金属 + 酸 | 金属排在氢前，且酸非氧化性 | 盐 + H₂ |
| 金属 + 盐 | 金属比盐中金属活泼、盐可溶、非常活泼金属 | 新盐 + 新金属 |
| 酸 + 碱 | — | 盐 + H₂O |
| 酸 + 碳酸盐 | 阴离子为 CO₃²⁻ / HCO₃⁻ | 盐 + H₂O + CO₂ |
| 酸 + 盐 | 生成沉淀，或强酸制弱酸 | 新酸 + 新盐 |
| 碱 + 盐 | 双方可溶且生成沉淀 | 新碱 + 新盐 |
| 盐 + 盐 | 双方可溶且生成沉淀 | 两种新盐 |
| 碱性氧化物 + 酸 | — | 盐 + H₂O |
| 碳 / 氢气 + 金属氧化物 | 金属活动性 ≤ 锌，高温还原 | 金属 + CO₂ / H₂O |
| 酸性氧化物 + 碱 | 碱可溶 | 盐 + H₂O |
| 金属 + O₂ / Cl₂ | 活动性 ≤ 铜（铁交给手写表） | 氧化物 / 氯化物 |
| 铵盐 + 碱 | 碱可溶 | 新盐 + NH₃ + H₂O |

3. 溶解性表用代码实现（硝酸盐/氯化物/硫酸盐/碳酸盐/氢氧化物/硫化物），
   不逐条写死
4. 系数不手写，用暴力搜索求最小整数比

回归测试在 `scripts/chem-check.ts`，50+ 条正反例，包含「必须不反应」的负例
（Cu + HCl、Fe + ZnSO₄、NaCl + Na₂SO₄、CuO + H₂O 等）。
**改规则后必须跑 `chem-check`，它比数值问题严重得多。**

测试末尾会打印「反应库规模」——全部物质两两组合里有多少组能反应。
这是衡量「反应自由多样」的指标，当前是 **468 / 4753 组（9.8%）**。

已知取舍：`硫酸` 这一张卡同时代表稀硫酸和浓硫酸，
Cu + H₂SO₄ 走的是浓硫酸加热版（表里带 trap 说明），界面会显示「加热」条件。

## 5. 年级分层（已确认方案）

四条线 × 12 关，但共享内容池（26 个关卡单元）：

| 年级线 | 编排 |
|---|---|
| 高三线（先做） | 初中 4 + 高一 4 + 高三 4 |
| 高二线 | 初中 4 + 高一 4 + 选必 4 |
| 高一线 | 初中 4 + 高一 8 |
| 初三线 | 初中 12 |

前 4 关对所有年级相同——它们同时承担新手教程，任何年级都从这里进。

**数据形态**：`levels.json` 每关带 `lines`（数组，属于哪几条线）与 `order`（线内序号）。
同一关写进多条 `lines` 就能被多条线共用，**不复制关卡**。
「下一关」按线内 `order` 走（`nextLevelInLine`），不靠 id 递增——否则新增的
101/201/301 会接错线。

## 6. 内容规范

- 铝一律写 `Na[Al(OH)4]`（四羟基合铝酸钠）。人教版必修一自 2023 年印刷版起已全面替换偏铝酸钠
- 初中按 2024 新版教材（11 单元，原「酸和碱」+「盐 化肥」合并为「常见的酸、碱、盐」）
- 每条方程式必须带：类型、条件、现象、教材出处、高频度（1–3 星）
- 经典陷阱写进 `trap` 字段，关卡里作为提示展示（例：Fe 与稀酸生成 Fe²⁺ 而非 Fe³⁺；
  Al³⁺ 用氨水沉淀而不用 NaOH；稀硝酸生成 NO 而非 NO₂）

## 7. 技术形态与部署

纯前端静态站点，无后端、无账号、无网络请求。

| 产物 | 命令 | 说明 |
|---|---|---|
| 网页 | `pnpm build` | `dist/`，任意静态托管 |
| 单文件 | `pnpm build:single` | `dist-single/index.html`，双击即玩（所有资源内联） |

单文件版的两个已知限制：`file://` 下 `localStorage` 可能不可用（存档退化为内存），
以及会带浏览器工具栏（可配一个 `.bat` 用 `--app` 模式启动）。

### 部署选型

| 方案 | 备案 | 国内速度 | 上线时间 |
|---|---|---|---|
| Cloudflare Pages + 自有域名 | 不需要 | 中等 | 5 分钟 |
| 阿里云 OSS 香港 + 自有域名 | 不需要 | 较好 | 半天 |
| 阿里云 OSS 大陆 + 自有域名 | **必须 ICP 备案** | 最好 | 2–4 周（赶不上 12-01） |

结论：先 Cloudflare Pages 上线拿链接，域名买好解析过去；备案留到赛后。
