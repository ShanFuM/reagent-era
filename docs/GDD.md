# 《试剂纪元》设计文档（GDD）

版本 0.1 · 2026-11-14

---

## 1. 定位

**一句话**：你被困在元素裂谷，手上只有随机发放的试剂。让两种物质反应，才能伤到怪物。

| 维度 | 取值 |
|---|---|
| 类型 | 回合制卡牌对战 / 教育向 |
| 平台 | 网页（横屏 16:9），可打单文件离线包 |
| 单局时长 | 4–9 回合，约 60–90 秒 |
| 总时长 | 12 关，约 15 分钟 |
| 教学范围 | 人教版九年级 → 必修第一册/第二册 → 选择性必修1 |
| 明确不做 | 元素周期律、有机化学 |

**核心取舍**：玩家不手写化学式，而是**从手牌里挑物质 + 判断能否反应 + 配平**。
理由：书写化学式会把节奏拖成做题；而「判断两种物质能不能反应」才是初中化学最核心的能力。
配平作为**可选的额外奖励**，而不是强制关卡。

## 2. 核心循环

```
一局战斗
 ├─ 每回合：重新发一手「必定能打」的牌（某条反应所需物质 + 3 张干扰牌）→ 选任意张 → 出招
 │    ├─ 不能反应 → 浪费一回合，敌方白打一次（惩罚判断失误）
 │    └─ 能反应 → 立即结算基础伤害
 │         └─ 配平面板（8–15 秒，可跳过）
 │              ├─ 跳过/超时   ×1.0
 │              ├─ 配平正确    ×1.15 +1 能量
 │              └─ 完美配平    ×1.30 +2 能量（剩余时间 > 一半）
 └─ 敌方回合：攻击或技能 → 弃掉整手 → 重新发牌 → 下一回合
```

> **发牌规则（2026-11-28 改）**：每回合开始发一手新牌，构成固定为
> 「一条可打反应所需的物质各一张 + 3 张干扰牌」，所以手牌数 = 反应物数 + 3（通常 5–6 张）。
> 出过的牌进弃牌堆，剩下的整手弃掉；牌堆不够时自动把弃牌洗回来。
> 有工序的阶段优先发当前工序那一步需要的牌，保证「卡关」不会变成「卡牌」。

> 选择数量不设上限：有些方程式本身就是三四个反应物
> （`4Fe + 3O₂ + 6H₂O`、`Al₂O₃ + 2NaOH + 3H₂O`），限制成 2 张会把它们全部堵死。

**能量**用于「强化」：消耗 1 点让这一击 ×1.25。
于是闭环成立：**配平换能量 → 能量换伤害**。配平从考试变成了资源操作。

**回合上限**：`16 + 敌人总血量/120 + 每多一个阶段 ×4`。第 12 关三阶段共 1000 血，上限 32 回合；
普通关卡仍是原来的公式，手感不变。超出即失败——这是防止玩家靠穷举试出反应的唯一手段。

## 3. 伤害模型

```
伤害 = 18 × 类型系数 × 条件系数 × 配平精度 × 弱点倍率 × (1 + 连击) × 强化 × 护甲
```

### 3.1 类型系数与附加效果

| 类型 | 系数 | 附加效果 |
|---|---|---|
| 中和 | 1.0 | 净化：清除自身异常 |
| 沉淀 | 1.1 | 成壳：自身 +12 护盾 |
| 复分解 | 1.1 | 成壳：自身 +12 护盾 |
| 置换 | 1.2 | 腐蚀：敌方护甲 −1 |
| 分解 | 1.2 | 催化：额外抽 1 张 |
| 产气 | 1.3 | 窒息：敌方下回合伤害 −30% |
| 化合 | 1.5 | — |
| 氧化还原 | 1.6 | 灼烧：敌方 3 回合持续掉血 |
| 燃烧 | 2.0 | 灼烧 |

### 3.2 条件系数

常温 1.0 / 催化 1.15 / 加热 1.25 / 点燃 1.3 / 通电 1.3 / 高温 1.4

### 3.3 弱点与抗性

每个敌人有 `weakness` 与 `resist` 两个反应类型列表，命中弱点 **×2**，被抗性削弱 **×0.5**。
这是「化学知识 → 战术」的唯一转化点：打对类型比配平快更重要。

### 3.4 其他

- 连击：连续命中弱点，每次 +10%，上限 +50%
- 护甲：`max(0.4, 1 − 护甲 × 0.12)`
- 灼烧：每回合固定 6 点

### 3.4.1 收尾门槛（第 7 关起，2026-11-28）

第 7–12 关带 `"requireSkill": true`：敌人血量归零时，如果这一局**既没有一次完美配平、
也没有用过一次强化**，最后一击会被弹开——敌人保留 1 点血，日志提示补条件，必须做到其中之一才能结算胜利。

**范围**：四条年级线的第 7–12 关，共 20 关（高三 7–12、高一/高二 7–8 与 20x/30x、初三 103–108）。

- 数据开关：关卡的 `requireSkill` 字段（`levels.json`）
- 判定在引擎的 `resolveEnemyDefeat()`，UI 只读 `skillGate()` 的结果
- 门槛只挡「最终结算」，不挡多阶段 Boss 的阶段切换
- 顶部有状态药丸：`收尾需：完美配平 ×1 或 强化 ×1` → 达成后变绿

### 3.5 已经过模拟验证

`scripts/sim.ts` 用随机策略把 12 关各跑 60 局，检查卡死与胜负分布。
**任何数值调整后必须重跑**，目标：普通关 4–7 回合、Boss 7–10 回合、模拟胜率 85–95%。

## 3.6 反应判定：规则引擎（不是查表）

早期版本只认手写反应表，表里没有的配对一律判「不反应」——
Zn + CuSO₄ 这种教科书反应都会被拒。现在是三层结构：

```
lookupReaction(a, b)
  ├─ 1. 手写反应表命中 → 直接用（有现象、教材出处、陷阱提示）
  ├─ 2. 规则引擎推断 → 产物 + 类型 + 条件
  └─ 3. 通用配平器求系数 → 定稿；求不出则判「不反应」
```

规则引擎（`src/engine/chem.ts`）的做法：

1. 用「枚举所有阴阳离子组合」反查化学式，得到每种物质的离子构成
2. 按物质类别套规则：

| 规则 | 判断依据 | 生成物 |
|---|---|---|
| 金属 + 酸 | 金属排在氢前，且酸非氧化性 | 盐 + H₂ |
| 金属 + 盐 | 金属比盐中金属活泼、盐可溶、非常活泼金属 | 新盐 + 新金属 |
| 酸 + 碱 | — | 盐 + H₂O |
| 酸 + 碳酸盐 | 阴离子为 CO₃²⁻ / HCO₃⁻ | 盐 + H₂O + CO₂ |
| 酸 + 盐 | 生成沉淀，或强酸制弱酸 | 新酸 + 新盐 |
| 碱 + 盐 | 双方可溶且生成沉淀 | 新碱 + 新盐 |
| 盐 + 盐 | 双方可溶且生成沉淀 | 两种新盐 |
| 碱性氧化物 + 酸 | — | 盐 + H₂O |

3. 溶解性表用代码实现（硝酸盐/氯化物/硫酸盐/碳酸盐/氢氧化物/硫化物），
   不逐条写死
4. 系数不手写，用暴力搜索求最小整数比

回归测试在 `scripts/chem-check.ts`，46 条正反例，包含「必须不反应」的负例
（Cu + HCl、Fe + ZnSO₄、NaCl + Na₂SO₄ 等）。
**改规则后必须跑 `chem-check`，它比数值问题严重得多。**

已知取舍：`硫酸` 这一张卡同时代表稀硫酸和浓硫酸，
Cu + H₂SO₄ 走的是浓硫酸加热版（表里带 trap 说明），界面会显示「加热」条件。

### 12 关分阶段设计（已实现）

第 12 关「裂谷之核」是三阶段 Boss，阶段数据在 `levels.json` 的 `phases` 数组里：

| 阶段 | 名称 | 血量 | 攻击 | 护甲 | 弱点 | 工序 |
|---|---|---|---|---|---|---|
| 1 | 工业流程 | 130 | 16 | 1 | 复分解 / 沉淀 / 氧化还原 / 分解 | r85 → r86 → r87 → r88 |
| 2 | 推断链 | 120 | 17 | 1 | 氧化还原 / 化合 / 分解 / 沉淀 | r93 → r94 → r95 |
| 3 | 综合 | 150 | 22 | 2 | 复分解 / 沉淀 / 氧化还原 / 分解 / 化合 | 无 |

- **阶段切换**：阶段血量归零不等于胜利。切到下一阶段时玩家回复 30 HP（不超过上限）、
  能量回满、护盾清零、工序重置，敌方血量/攻击/护甲/弱点换成新阶段的值；最后阶段打完才判胜。
  战斗内有一块独立的阶段切换横幅，实验记录里同步写阶段标题与资源变化。
- **工序推进**：处于有 `required` 的阶段时，按顺序打出当前步骤指定的反应才算推进。
  推进时把该反应的主要产物自动加入手牌——优先取「非气体、非沉淀」的第一个产物，
  都不满足时退回第一个产物。这条规则不写死物质：r85 的 `Na[Al(OH)4]` 就是这样续上的。
- **工序惩罚**：打出其它能反应的反应仍结算伤害，但伤害 ×0.5；不锁死，可以继续试。
  工序走完后不再有折半惩罚。
- **链条进度 UI**：敌人血条下方显示工序链（阶段 1 四道工序；阶段 2 是
  NH₃ → NO → NO₂ → HNO₃），状态分为已完成 / 当前 / 未完成，节点用各步第一个产物。
- **回合上限**：`16 + 总血量/120 + 每多一个阶段 ×4`；第 12 关 400 血、三阶段 → 27 回合上限（实测 12 回合左右打完）。
  单阶段关卡该项为 0，公式与原来完全一致。
- **数值目标**：`check:sim` 随机策略下第 12 关胜率 45%–60%（600 局实测约 54%），
  其它 11 关的回合数与胜率必须与改动前一致。

## 5. 年级分层（已确认方案）

四条线 × 12 关，但共享内容池（26 个关卡单元）：

| 年级线 | 编排 |
|---|---|
| 高三线（先做） | 初中 4 + 高一 4 + 高三 4 |
| 高二线 | 初中 4 + 高一 4 + 选必 4 |
| 高一线 | 初中 4 + 高一 8 |
| 初三线 | 初中 12 |

前 4 关对所有年级相同——它们同时承担新手教程，任何年级都从这里进。

**数据形态**：`levels.json` 每关带 `lines`（数组，属于哪几条线）与 `order`（线内序号）。
同一关写进多条 `lines` 就能被多条线共用，**不复制关卡**。
「下一关」按线内 `order` 走（`nextLevelInLine`），不靠 id 递增——否则新增的
101/201/301 会接错线。

## 6. 内容规范

- 铝一律写 `Na[Al(OH)4]`（四羟基合铝酸钠）。人教版必修一自 2023 年印刷版起已全面替换偏铝酸钠
- 初中按 2024 新版教材（11 单元，原「酸和碱」+「盐 化肥」合并为「常见的酸、碱、盐」）
- 每条方程式必须带：类型、条件、现象、教材出处、高频度（1–3 星）
- 经典陷阱写进 `trap` 字段，关卡里作为提示展示（例：Fe 与稀酸生成 Fe²⁺ 而非 Fe³⁺；
  Al³⁺ 用氨水沉淀而不用 NaOH；稀硝酸生成 NO 而非 NO₂）

## 7. 技术形态与部署

纯前端静态站点，无后端、无账号、无网络请求。

| 产物 | 命令 | 说明 |
|---|---|---|
| 网页 | `pnpm build` | `dist/`，任意静态托管 |
| 单文件 | `pnpm build:single` | `dist-single/index.html`，双击即玩（所有资源内联） |

单文件版的两个已知限制：`file://` 下 `localStorage` 可能不可用（存档退化为内存），
以及会带浏览器工具栏（可配一个 `.bat` 用 `--app` 模式启动）。

### 部署选型

| 方案 | 备案 | 国内速度 | 上线时间 |
|---|---|---|---|
| Cloudflare Pages + 自有域名 | 不需要 | 中等 | 5 分钟 |
| 阿里云 OSS 香港 + 自有域名 | 不需要 | 较好 | 半天 |
| 阿里云 OSS 大陆 + 自有域名 | **必须 ICP 备案** | 最好 | 2–4 周（赶不上 12-01） |

结论：先 Cloudflare Pages 上线拿链接，域名买好解析过去；备案留到赛后。
